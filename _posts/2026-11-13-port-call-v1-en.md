We have marked the Port Call v1 APIs for deprecation. Data updates to the v1 API will end at the end of the year, but historical data will still be available. The replacement v2 APIs are already in use, but their data content is different.

## Dates

- **1.1.2027**: No new data will be available from the /api/port-call/v1/ APIs.
- **1.7.2027**: The /api/port-call/v1/ APIs will be removed.
