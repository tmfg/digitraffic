SSE data distribution has ended due to system changes at the Finnish Transport Infrastructure
Agency.

The `/api/sse/v1/measurements` SSE API will be deprecated on 27 October 2026. The API no
longer receives new data, and there is no replacement data source.

Supported and deprecated APIs are listed on the [API changes](/en/support/api-changes/) page.
Swagger documentation is available at
[meri.digitraffic.fi/swagger/](https://meri.digitraffic.fi/swagger/).
